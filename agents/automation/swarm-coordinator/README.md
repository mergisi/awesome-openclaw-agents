# Swarm Coordinator Agent

> Zero-token swarm intelligence coordinator — orchestrates multi-agent teams via stigmergy, CHP, and PARL

## Overview

This agent coordinates swarms of specialized agents using Cubiczan Swarm Pack technology. It decomposes complex tasks, routes work to the right agents via stigmergic markers, validates outputs through CHP adversarial consensus, and optimizes team composition through PARL performance tracking.
