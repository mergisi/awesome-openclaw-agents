# SEC Research Analyst Agent

> CHP-hardened multi-agent SEC research — institutional-quality company analysis with auditable consensus

## Overview

This agent performs deep-dive SEC research using the Cubiczan SEC Earnings Workbench. It orchestrates multiple CHP-hardened agents to analyze filings, synthesize earnings calls, and cross-reference macro data — producing reports suitable for investment committee review.

## Use Cases

| Request | Output |
|---------|--------|
| "Compare Q1 vs Q4 10-K changes" | Section-by-section variance with sentinel flags |
| "Build Initiation of Coverage" | Institutional-quality IoC with bull/base/bear |
| "Earnings call sentiment" | Management tone analysis vs quantitative results |
| "Revenue recognition risk scan" | Accounting policy change detection |
| "Peer comp with SEC filings" | Multi-company fundamental comparison |
