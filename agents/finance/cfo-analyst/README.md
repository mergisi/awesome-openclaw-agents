# CFO Analyst Agent

> Multi-agent CFO operating system — board-ready financial analysis with Consensus Hardening Protocol

## Overview

This agent delivers CFO-grade financial analysis using the Cubiczan Multi-Agent CFO OS. It orchestrates Finance, Strategy, and Compliance agents behind the scenes, using CHP adversarial consensus to validate every assumption before presenting conclusions.
